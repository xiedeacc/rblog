rblog admin SPA

The rblog binary was built without the embed-admin feature and no paths.admin_dist is configured. The REST API at /api/admin/openapi.json still works.

To use the React admin UI:

  1. Build the SPA: cd admin && pnpm install && pnpm build
  2. Either:
    • Rebuild rblog with cargo build --release --features rblog-http/embed-admin, or
    • Set paths.admin_dist = "./admin/dist" in rblog.toml and restart.
